# Contributing to ProtocolWarden

This repository is the GitHub profile README for the ProtocolWarden ecosystem. It is the front door at `github.com/ProtocolWarden`.

## What Lives Here

- `README.md` — the profile overview rendered on the GitHub org page

## Before You Start

- Check open issues before proposing changes
- For significant rewrites, open an issue first to discuss the approach
- Keep content public-safe — no private topology, private paths, or operational secrets

## Making Changes

1. Fork the repository
2. Create a branch: `git checkout -b your-branch-name`
3. Make your changes to `README.md`
4. Open a pull request

## Content Guidelines

- Keep descriptions accurate and up to date with the current ecosystem
- Link to the public-facing repos and documentation, not private resources
- Use architecture language consistent with the ProtocolWarden ecosystem vocabulary

## Pull Requests

- Keep PRs focused on one concern
- Describe what changed and why in the PR description

## Code of Conduct

This project follows the [Contributor Covenant v2.1](CODE_OF_CONDUCT.md). By participating you agree to uphold its standards.
