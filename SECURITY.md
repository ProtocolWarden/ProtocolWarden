# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| `main`  | Yes       |

Only the current `main` branch receives fixes.

## Reporting a Vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Report security issues privately by emailing **coding.projects.1642@proton.me**.

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations (optional)

You will receive an acknowledgment within 72 hours. We aim to release a fix within 14 days of a confirmed report, depending on severity and complexity.

## Scope

This repository is the GitHub profile README for ProtocolWarden. It contains no executable code, credentials, or sensitive operational data. The primary security surface is accidental disclosure of private information in the profile description or linked content.

## Out of Scope

- Vulnerabilities in GitHub's platform itself
- Issues in linked repositories (report those to their respective repos)
